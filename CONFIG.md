# Configuration

Every setting lives in `BepInEx\config\com.ivmakk.thelastplagueblight.mapoverhaul.cfg`, written the first time you run the game with the mod installed. The legend on the Map writes the `Map` settings when you click a row. You can also edit the file with any text editor while the game is closed. Changes in the file apply at the next game start.

## Map

| Setting | Default | Values | What it does |
|---|---|---|---|
| `ShowCabins` | `true` | `true` / `false` | Shows the cabin icons on the Map. The Cabins row of the legend. |
| `ShowCaves` | `true` | `true` / `false` | Shows the cave icons on the Map. The Caves row of the legend. With `false`, the ore lines of the caves are hidden with them. |
| `ShowTin` | `true` | `true` / `false` | Shows the dots of the Cassiterite deposits. The Tin row of the legend. |
| `ShowCopper` | `true` | `true` / `false` | Shows the dots of the Copper-rich Rock deposits. The Copper row of the legend. |
| `ShowIron` | `true` | `true` / `false` | Shows the dots of the Iron-rich Rock deposits. The Iron row of the legend. The cave hover texts keep their iron lines. |
| `ShowSilver` | `true` | `true` / `false` | Shows the dots of the Silver-rich Rock deposits. The Silver row of the legend. |
| `ShowFogOfWar` | `true` | `true` / `false` | Darkens the land that the game has not generated yet. The Fog of war row of the legend. |

## General

| Setting | Default | Values | What it does |
|---|---|---|---|
| `Verbose` | `false` | `true` / `false` | Writes extra diagnostic lines to the BepInEx log for troubleshooting. Keep off in normal play. |
